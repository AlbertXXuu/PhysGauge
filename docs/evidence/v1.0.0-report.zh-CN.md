## 解释边界

这项受控校准结果表明，某个指标可能漏掉该解析碰撞世界中已知的物理或因果扰动。它**没有**测量学习得到的世界模型、建立真实世界模型排名，也不能证明所有公开排行榜都有同样的失败。PhysGauge 可作为指标单元测试，在更广泛的基准评测和人工研究之前运行。

`pixel_frechet` 是基于极低维像素特征计算的 Fréchet 距离，设计上刻意减少依赖，与 Inception FID 和 FVD 不同。冻结报告中所称的“对倒序帧集精确失明”，展示了舍弃时间顺序的后果；其浮点数值含义与帧倒序操作应结合上述勘误说明理解。
