# Security policy

## Supported version

Security fixes are provided for the latest `1.x` release.

## Reporting

Please use GitHub's private vulnerability reporting for
[AlbertXXuu/PhysGauge](https://github.com/AlbertXXuu/PhysGauge/security/advisories/new).
Do not include secrets, private datasets, or exploit details in a public issue.

PhysGauge performs local numerical computation and writes only to the output directory supplied by
the user. It makes no network calls and does not execute submitted model code.
